# Security policy

Report a vulnerability privately to **security@supersolution.io** (or contact@supersolution.io) with the package, version and steps to reproduce. Please do not open a public issue for an unfixed vulnerability. We acknowledge a report within 3 business days and aim to ship a fix or a mitigation within 30 days for confirmed issues.

Supported versions: the latest published `0.x` line of the `@supersolutions/super-editor-*` packages.

What the editor does and does not protect against, and what a host must add (authentication, authorization, durable compare-and-swap, URL fetching policy), is described in [docs/SECURITY.md](docs/SECURITY.md).
